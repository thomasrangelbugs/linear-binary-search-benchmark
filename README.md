# Busca linear x busca binaria

Projeto estatico para a atividade U2.

## O que a pagina faz

- Carrega o arquivo `br-utf8.txt` para memoria.
- Separa a frase do enunciado em palavras.
- Mede o tempo de busca de cada palavra com busca linear e busca binaria.
- Exibe os resultados em milissegundos (ms).

## Publicacao no Netlify

1. Envie esta pasta para um repositorio no GitHub.
2. No Netlify, importe o repositorio.
3. Use a raiz do projeto como pasta publicada. O arquivo `netlify.toml` ja define isso.

## Fonte dos dados

- IME-USP: https://www.ime.usp.br/~pf/dicios/
- Arquivo usado: https://www.ime.usp.br/~pf/dicios/br-utf8.txt
